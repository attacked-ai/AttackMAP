Side-by-side comparison

Both designs open with the same header, key figures and Executive Summary. They differ in what comes after it, and in standard reports also in where Case progression sits. The yellow-dot values are measured live from the frames above in Free reader mode, for the selected report and viewport.

Checklist

How to evaluate

Run through these for each report you review. There is no recommendation here; the team decides.

  1. Scroll to the end in both designs at Desktop width, with Sync scroll on, and note where each subscription prompt appears.
  2. Switch to Mobile 390 and repeat. Compare page length and check the sticky Subscribe bar in B.
  3. Switch Reader to What unlocks to see B's free page beside the full report a subscriber reads; Sync scroll lines up the sections. Subscriber shows the full report in both columns.
  4. Click Subscribe in each design. Clicks are caught on this page and reported in a notice, so nothing navigates away.
  5. Check the NATS flagship and one standard report such as ATK-EV-067. NATS has extra sections, so the counts differ, and Case progression is free in A only on standard reports.
